# ☕ Kaffestuga

Landing page responsive desarrollada para Kaffestuga, un restaurante y cafetería ubicado en un entorno natural.

## 📌 Descripción

Sitio web desarrollado como una landing page informativa para presentar el establecimiento, sus servicios, información general y medios de contacto.

El proyecto está enfocado en ofrecer una experiencia visual sencilla, adaptable a diferentes dispositivos y con navegación por secciones.

## 🚀 Características

- Diseño responsive.
- Navegación por secciones.
- Sección de presentación.
- Sección "Nosotros".
- Información de servicios.
- Galería de imágenes.
- Formulario de contacto funcional.
- Enlaces a WhatsApp, Facebook, correo electrónico y ubicación.
- Diseño adaptado para dispositivos móviles.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts
